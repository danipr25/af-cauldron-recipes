# Cauldron Recipes

A mod for **Alchemy Factory** that adds a Cauldron Recipes tab to the TAB menu: search, Normal and Advanced modes, and the recipes you have already discovered. Requires AF Mod Loader and AF Mod Loader API.

Status: early development. Not usable yet.

Unofficial fan project. Alchemy Factory belongs to its developers.
